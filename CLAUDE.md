# Storyverse project context

Storyverse is a standalone collaborative visual-storytelling workspace built with Next.js, React, TypeScript, Zustand, Zod, and optional Supabase persistence.

The application must run without cloud credentials. Keep deterministic fixture and mock modes working, and route optional local model calls through `src/lib/ai/provider.ts`.

Prioritize the complete branch, review, and selective-merge journey. AI output remains advisory and requires human approval before changing story data. Never commit secrets or local environment files.
