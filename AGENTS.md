# Storyverse Repository

## Mission

Build Storyverse as a reliable standalone visual-storytelling workspace for small creative teams.

## Working agreements

- Prefer a small, reliable end-to-end workflow over unfinished breadth.
- Treat accessibility, privacy, security, responsible AI, and human oversight as product requirements.
- Keep the default setup runnable without cloud credentials.
- Never commit keys, credentials, private data, generated secrets, or local environment files.
- Document every optional dependency and environment variable.
- Add or update tests for important behavior and run relevant tests before declaring work complete.
- Keep model integrations behind the provider-neutral adapter in `src/lib/ai/provider.ts`.

## Decision priorities

1. A working, understandable product.
2. User value and a clear creative workflow.
3. Technical quality and responsible behavior.
4. Memorable interaction design.
5. Additional features.
